# Конвойный кубок

Пиксельная браузерная гонка на HTML5 Canvas, в духе старых Flash-игр. Синяя, красная и жёлтая машины с зелёными полосками и синими мигалками соревнуются на трассе длиной 1 400 метров. Финиш — у ворот исправительной колонии.

На обочинах расположены трибуны со зрителями в разных оттенках синей формы и головных уборах. На дороге — препятствия и бонусные персонажи в чёрной форме с белыми светоотражающими полосами и нагрудными знаками. Столкновения аркадные, без крови.

## Запуск

Откройте `index.html` в современном браузере. Установка, сборка, Flash Player, внешние ресурсы и ключи не нужны. Для разработки можно запустить сервер:

```sh
cd /workspace/1
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте адрес сервера на порту 8000.

## Управление

- A / D или ← / → — руль.
- W / ↑ — газ, S / ↓ — тормоз. Без нажатий машина едет сама.
- Пробел или «Турбо» — ускорение на 1,4 секунды, восстановление 5 секунд.
- P, Esc или кнопка паузы — пауза / продолжение.
- На телефоне — удерживайте стрелки на игровом поле или ведите пальцем по дороге. Турбо можно нажать вторым пальцем.

## Правила

- Игрок управляет синей машиной. Красная и жёлтая — самостоятельные соперники.
- Фигурка на дороге даёт +100 очков. Таран соперника даёт +50.
- Препятствия, забор и тараны повреждают кузов и временно замедляют машину. При 0% прочности игрок сходит с дистанции.
- Соперники тоже сталкиваются и получают повреждения; после поломки восстанавливаются с задержкой.
- Финишный бонус: 1-е место +1000, 2-е +500, 3-е +250.
- Порядок финиша определяется временем пересечения линии. Участники, ещё не финишировавшие, расположены по текущему прогрессу.
- Рекорд очков сохраняется в этом браузере. Переключение вкладки автоматически ставит гонку на паузу.
